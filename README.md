# Quiz App

A simple and interactive Quiz Application built using **HTML, CSS, and JavaScript**.
This project allows users to answer multiple-choice questions and view their score instantly after completing the quiz.

---

## 🚀 Features

* Multiple-choice quiz questions
* Instant score calculation
* Responsive and user-friendly design
* Interactive UI
* Beginner-friendly project

---

## 📂 Project Structure

```bash
Quiz-App/
│── index2.html
│── style2.css
│── hello2.js
│── README.md
```

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

---

## ▶️ How to Run the Project

1. Download or clone this repository
2. Open the project folder
3. Run `index2.html` in your browser

## 📸 Preview

The Quiz App displays questions with multiple options and calculates the final score based on the user's answers.
